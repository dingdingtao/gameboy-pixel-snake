# Game Boy Pixel Snake

一款 Game Boy 风格的像素贪吃蛇。复古掌机外壳、绿色点阵屏幕和可点击的方向键都在一个 HTML 文件中实现，打开浏览器就能玩。

## 特点

- **零依赖**：原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。
- **复古画面**：Canvas 采用 160 × 144 像素分辨率，棋盘为 20 × 18 格。
- **双重操作**：支持方向键、WASD，以及鼠标或触屏操作屏幕按钮。
- **逐步加速**：每吃到一个食物加 10 分，移动间隔从 150 毫秒逐步缩短，最低为 70 毫秒。
- **最高分保存**：通过浏览器 localStorage 保存本地最高分；存储不可用时仍可游玩。
- **暂停与重开**：支持手动暂停，页面切换到后台时也会自动暂停。
- **输入保护**：禁止直接反向移动，并缓存最多两次转向。

## 运行

下载项目后，用现代浏览器打开 `index.html` 即可，无需联网。

也可以在项目目录启动本地静态服务器（需要 Python 3）：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

最高分保存在当前浏览器的当前站点下，不会在设备或浏览器之间同步。直接打开文件时，存储行为可能因浏览器而异；使用本地服务器可获得更稳定的存储环境。

## 操作

| 操作 | 键盘 | 屏幕按钮 |
| --- | --- | --- |
| 转向 | 方向键 / WASD | 十字方向键 |
| 开始游戏 | Enter；待机时也可按空格或方向键 | A / START |
| 暂停或继续 | Enter / 空格 / P | A / B / START |
| 重新开始 | R；结束后也可按 Enter | SELECT；结束后也可按 A / START |

键盘上的 A 属于 WASD 方向输入，与屏幕上的 A 按钮功能不同。

## 规则

控制蛇吃到食物，每次得 10 分并增长一格。撞墙或撞到自己的身体会结束游戏，填满整个棋盘即可获胜。蛇不能直接掉头。

## 调整游戏

在 `index.html` 的脚本顶部修改以下常量：

| 常量 | 默认值 | 含义 |
| --- | --- | --- |
| `COLS` / `ROWS` | `20` / `18` | 棋盘列数与行数 |
| `CELL` | `8` | 每格像素数 |
| `BASE_SPEED` | `150` | 初始移动间隔，单位为毫秒 |
| `MIN_SPEED` | `70` | 最短移动间隔 |
| `SPEED_STEP` | `4` | 每吃到一个食物减少的移动间隔 |
| `HI_KEY` | `gb-pixel-snake-hi` | 最高分存储键名 |

修改棋盘尺寸时，也要检查 `resetBoard()` 中的初始蛇身坐标是否仍在棋盘内。

界面配色集中在 CSS 的 `:root` 中。当前版本没有音效，机身上的声效文字为外观装饰。
